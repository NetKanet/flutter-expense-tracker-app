# Flutter Expense Tracker App

A personal expense tracker app built with Flutter & Dart, following [Academind's Flutter & Dart - The Complete Guide](https://www.udemy.com/course/learn-flutter-dart-to-build-ios-android-apps/) on Udemy.

## Features

- Add and categorize expenses
- View expense list with details
- Visual chart for spending overview

## What I Learned

- **Theming & Styling** — ThemeData, ColorScheme, dark/light mode
- **Complex Widgets** — ListView, Card, Dismissible, SnackBar
- **User Input** — TextField, DropdownButton, DatePicker, showModalBottomSheet
- **Responsive & Adaptive UI** — MediaQuery, LayoutBuilder, Platform checks
- **State Management** — Managing lists of data with setState()

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- An emulator or physical device

### Run

```bash
git clone https://github.com/NetKanet/flutter-expense-tracker-app.git
cd flutter-expense-tracker-app
flutter pub get
flutter run
```
